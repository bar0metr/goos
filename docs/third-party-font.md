# Built-in framebuffer font provenance

GoOS embeds the `512_8_bold` bitmap data from Alexey Frunze's `512_8`
repository at commit `726f6fa1d09775f9962a47fe78ce1aeacaa4cf34`:

<https://github.com/alexfru/512_8>

The upstream project dedicates the font to the public domain under the
Unlicense. GoOS stores the generated byte table in
`kernel/framebuffer/font_data.go`. The runtime exposes printable ASCII,
Russian Cyrillic letters including `Ё` and `ё`, and the upstream replacement
glyph. Source rows are doubled vertically to form fixed 8x16 cells.
