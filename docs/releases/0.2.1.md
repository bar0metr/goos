# GoOS 0.2.1

GoOS 0.2.1 is the Linux process-composition release. A Linux program can now
start, replace, connect, wait for, and signal other Linux programs, and a
static BusyBox `sh` runs non-interactive command lines. BusyBox is no part of
the image: the session below adds it under `/system/linux` with
`make LINUX_EXTRA=/path/to/busybox`, which `make test-linux-busybox
BUSYBOX=/path/to/busybox` also does.

```text
goos> /system/linux/busybox sh -c '/system/linux/musl-hello one two'
argc=3
hello from musl
goos> /system/linux/busybox sh -c 'busybox echo A | busybox cat | busybox cat'
A
goos> /system/linux/busybox sh -c 'busybox false || busybox echo recovered'
recovered
goos> /system/linux/busybox sh /persist/test.sh
from-script
```

Every Linux descendant is an ordinary GoOS Process in the native registry,
scheduled, charged, and torn down like any other. Creating one grants no
authority the parent lacks.

## Highlights

- `fork`, `vfork`, and the process forms of `clone` create a child from a
  private copy of the caller's touched pages. Descriptors share their
  open-file descriptions (ADR 0158, ADR 0159).
- `execve` replaces a running image in place after preparing the new one
  completely; a failure leaves the old program running (ADR 0157).
- `wait4` reaps children by PID or by any, with `WNOHANG`, from bounded zombie
  records that carry the exit status or the terminating signal (ADR 0154,
  ADR 0160, ADR 0161).
- `pipe` and `pipe2` connect processes through native streams, with
  `PIPE_BUF` writes of 4096 bytes that never interleave (ADR 0162).
- Real signals: `SIGCHLD`, `SIGPIPE`, and those `kill` sends reach handlers on
  an x86_64 `rt_sigframe`, return through `rt_sigreturn`, interrupt blocked
  calls, and honor `SA_RESTART` (ADR 0163 to ADR 0167).
- `poll`, `ppoll`, `rt_sigsuspend`, and `pause` sleep on native readiness and
  signals, never in a loop (ADR 0168, ADR 0169, ADR 0172).
- A Linux program's x87 and SSE state survives a system call that returns at
  once, one that sleeps in the scheduler, and a signal handler: the frame
  carries an FXSAVE image and `rt_sigreturn` restores it. `fork`, `vfork`,
  and `clone` children inherit the parent's state, and `execve` resets it
  (ADR 0174).
- 74 Linux syscall numbers implemented, up from 59.
- VFS protocol version: **13**, unchanged.

## Implemented

### Process tree

- A bounded family registry links each Linux process to its parent and to a
  generation-safe GoOS Process, and keeps zombie records after the Process is
  gone. A family holds at most 16 running and zombie processes and all
  families at most 48. No Linux process, launched by PID 1 or forked, may take
  one of the last 16 of the 64 process slots, which stay for native processes.
  A full budget is `EAGAIN` for a fork and `LaunchResourceExhausted` for a
  launch (ADR 0154, ADR 0155).
- Parent exit hands running children to PID 1 and clears orphan zombies.
  `SIG_IGN` or `SA_NOCLDWAIT` on `SIGCHLD` leaves no zombie (ADR 0165).
- PID 1 holds no handle to a forked process and hears nothing of its exit.
  Ctrl-C on a Linux job ends the job's whole family (ADR 0170).

### Files across processes

- Per-process descriptor tables over reference-counted open-file
  descriptions: inherited and duplicated descriptors share position, status
  flags, stream endpoint, and directory cursor; close-on-exec stays per
  descriptor (ADR 0156).
- One VFS context per family serializes requests from its members in a
  bounded FIFO. The shared channel stays open until the last member exits.

### Calls

- `execve`: bounded argument and environment snapshots, a VFS-pinned copy of
  the executable, a prepared replacement address space, close-on-exec, and
  signal reset; static `ET_EXEC` and static PIE only (ADR 0157).
- `fork`, `vfork`, `clone(SIGCHLD)`, `clone(CLONE_VM|CLONE_VFORK|SIGCHLD)`.
  Thread, TLS, TID, and namespace flags are `EINVAL`.
- `wait4` with `WNOHANG`, `__WALL`, and `__WNOTHREAD`; `rusage` reports user
  time.
- `pipe`, `pipe2(O_CLOEXEC)`.
- `kill`, `tkill`, `tgkill` for the caller and its descendants only, never by
  Linux UID (ADR 0166).
- `rt_sigreturn`, `rt_sigsuspend`, `pause`.
- `rt_sigaction` refuses flags GoOS cannot honor.
- `poll`, `ppoll` with a temporary mask.
- A Linux program gets `PATH=/system/linux` in place of the native default
  (ADR 0171).

### Validation

- `abi-probe` gains `fork`, `vfork`, `orphan`, `wait`, `pipe`, `signal`,
  `kill`, `eintr`, `poll`, `ppoll`, `hardening`, `fpstate`, `limits`,
  `family`, `path`, and `run`. Each mode that does not depend on GoOS prints
  the same lines on a real Linux 6.12 kernel, held to the exact Linux result.
- `abi-probe fpstate` loads XMM registers, MXCSR, and the x87 control word
  and checks that they come back from `getpid`, from a `nanosleep` that
  sleeps, in a `fork` child, and from a handler that clobbers them, nested or
  not, with an edited or null `fpstate` image. `abi-probe exec` checks that
  the new image starts from the initial state.
- `make test-linux-boot` runs every mode in one boot, then presses Ctrl-C on
  a Linux root and requires its forked child to be gone. `make
  test-linux-process`, `test-linux-exec`, `test-linux-fork`,
  `test-linux-pipe`, `test-linux-signals`, and `test-linux-poll` name the
  same run.
- `make test-linux-busybox BUSYBOX=path`, also `make test-linux-shell`,
  requires BusyBox `sh` to run programs by path and through `PATH`, report
  statuses, connect two- and three-stage pipelines, redirect, run a script,
  and collect a background job with `wait` (ADR 0172).
- `make test-linux-process-reference` names the strict real-kernel run.
- Validation builds fail a fork in the middle of its page copy and kill the
  VFS during an `execve`. The boot test requires the fork to leave no process,
  PID, page, description reference, or VFS-context reference behind, and the
  exec caller to continue in its old image (ADR 0173).

## Native changes

- A stream ring holds 8176 bytes in two pages instead of 4080 in one, so a
  4096-byte write fits whole (ADR 0162).
- Two kernel heap leaks are gone: a Linux launch no longer boxes its startup
  record, and copying a region map no longer builds a 6 KiB temporary.

Native programs, the native call ABI, and the native image format are
unchanged.

## Limits

This release runs x86_64 static programs, position-independent or not. It
has:

- no dynamic linker, `PT_INTERP`, or glibc;
- no threads, thread-form `clone`, or `futex`;
- no copy-on-write: `fork` copies every touched page, and a `vfork` child
  never shares the parent's memory;
- no process groups, sessions, or job control; no controlling terminal and no
  termios; Ctrl-C ends a whole Linux job and is no terminal `SIGINT`;
- signals delivered only at system call returns; `SIGHUP`, `SIGINT`,
  `SIGQUIT`, `SIGABRT`, `SIGKILL`, `SIGUSR1`, `SIGUSR2`, `SIGPIPE`, `SIGALRM`,
  `SIGTERM`, and `SIGCHLD` only; no alternate signal stack; x87 and SSE
  state only, since GoOS enables no AVX;
- `kill` that reaches only the caller and its descendants, never another
  family or a native process;
- no `select`, `epoll`, or nonblocking pipes; file I/O is never interrupted;
- no networking, `/proc`, `/sys`, or file-backed `mmap`;
- no Linux ownership or permission model.

[The ABI document](../architecture/linux-x86_64-abi.md) is the contract.
